# Changelog

## 0.1.0

- **Mod Settings** button on the title screen and **Mods** button in the pause menu open one settings menu for every installed BepInEx mod.
- Toggles, dropdowns, sliders, key bindings and text fields, chosen from each setting's type.
- Changes apply immediately and are saved to each mod's config file.
- Search across all mods, reset to default, and an Advanced filter.
- Reads ConfigurationManager-style tags (display name, order, hidden, advanced, read only) plus RestartRequired.
